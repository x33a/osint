# OSINT

A place for OSINT shenanigans: notes, techniques and CTF writeups from learning open-source intelligence (OSINT) — finding, verifying and connecting information from public sources.

This repo is a learning log: every technique here was worked out on a real challenge, with the commands, sites and dead ends that came with it.

## What's here

| Folder | What it holds |
| --- | --- |
| [ctf-writeups/](ctf-writeups/README.md) | Walkthroughs of OSINT CTFs, one folder per event. Answers are hidden behind spoilers. |
| [techniques/](techniques/README.md) | Reusable methods grouped by topic: accounts, domains, images and geolocation, public records, tracking. |
| [tools/](tools/README.md) | My toolkit: installs, GHunt setup, troubleshooting and cleanup. |

## Ethics

Everything here uses public sources, in the context of CTFs built for practice. Being public doesn't make every use okay: don't use these techniques to locate, harass or expose private individuals, and think twice before publishing anything that ties a real person to their home.
